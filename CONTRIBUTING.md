# Contributing

Use the Docker setup or the local development instructions. Submit focused changes with a clear description of the resulting behavior. Run the checks in README.md. Add tests for changes to user isolation, authentication, generation state transitions, or provider request contracts.

Follow Laravel Boost's generated guidelines and use shadcn components with the existing preset. Keep the app interface and generated outputs Burmese. Preserve keyboard navigation and mobile behavior. Do not commit credentials, databases, uploads, provider output, or build artifacts. Write respectful issues and pull requests.
